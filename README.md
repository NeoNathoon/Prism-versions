# Prism

Explorateur de fichiers pour Windows 11, transparent, avec onglets et recherche rapide.

## Installer

Télécharger **[Prism-setup.exe](https://github.com/NeoNathoon/Prism-versions/raw/main/Prism-setup.exe)**, puis l'ouvrir.

Windows peut afficher « Windows a protégé votre ordinateur » (l'installateur n'est pas signé par un éditeur connu) :
cliquer sur **Informations complémentaires**, puis **Exécuter quand même**.

## Mises à jour

Prism se met à jour tout seul au démarrage. Le bouton **Rechercher des mises à jour**, en bas de la barre latérale,
vérifie à la demande.

Ce dépôt ne contient que l'installateur et le fichier de version, publiés automatiquement.
